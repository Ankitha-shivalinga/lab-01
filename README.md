# Grade Classifier

This program asks the user to enter a mark out of 100 and reports the corresponding letter grade. It also validates the input and rejects empty, non-numeric, or out-of-range values.

## Setup

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

```
## Run

```text
python app.py
```

## Example

```text
Grade Classifier
----------------
Enter your mark out of 100: 85
Your mark is 85.0/100. Grade: A
```
## Known limitations

The program uses a simple letter-grade classification system and does not account for course-specific grading policies or weighting.
